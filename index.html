Sikaty

Freelance marketplace · UK-registered · 2023 → now
In production

Buyers post work, sellers deliver it, and the whole relationship runs through the platform: discovery, real-time messaging, orders, payment. I built the entire client-side application — from the first Bootstrap-to-Next.js migration through to the subscription checkout that's live today — and worked into the Django backend it talks to.

01

Seller onboarding

Multi-step profile wizard with per-step validation, unsaved-changes tracking, and a profile-strength score that updates as sellers type.

02

Real-time chat

WebSocket inbox and conversation view on a dual-channel design — one channel for notifications, one for the open thread — plus a mobile bottom-sheet UI.

03

Checkout & subscriptions

Stripe Elements and PayPal in a session-based flow, covering both one-off custom offers and recurring plans.

04

Order management

The full order flow migrated off Bootstrap: feed, details, requirements, deliveries — each rendered differently for buyer and seller.

05

Search & discovery

Paginated gig grid with bookmarking and autocomplete, backed by a word-tokenized Django search endpoint.

06

The design system

One typography, color and motion language applied across landing, blog, category browsing and help center.

About

I'd rather go deep on one real product than wide on ten demos.

Building one thing end to end meant owning the parts that never show up in a component library: state that has to survive a page refresh, checkout flows that can't fail quietly, chat that stays in sync across two WebSocket channels.

I like working close to the backend — not because I want to be a backend developer, but because the best frontend decisions come from knowing exactly what the API can and can't promise you.
