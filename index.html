Featured work

Sikaty

Freelance marketplace · UK-registered · Primary frontend developer
In production

Sikaty is a two-sided freelance marketplace — buyers post work, sellers deliver it, and the whole relationship runs through the platform: discovery, real-time messaging, orders, and payment. I built the entire client-side application, then wired it into a Django backend I also worked on — from the first Bootstrap-to-Next.js migration through to the subscription checkout flow live today.

Design system

Custom typography, color, and motion language applied consistently across every page — landing, blog, category browsing, help center.

Seller onboarding

Multi-step profile wizard with live validation, unsaved-changes tracking, and a profile-strength score that updates as sellers fill it in.

Real-time chat

WebSocket-driven inbox and chat with a dual-channel design — one channel for notifications, one for the open conversation — plus mobile bottom-sheet UI.

Order management

Migrated the full order flow off Bootstrap: feed, details, requirements, and deliveries, each rendered differently for buyer vs. seller.

Checkout & subscriptions

Stripe Elements and PayPal wired into a session-based checkout, covering both one-off custom offers and recurring subscription plans.

Search & discovery

Paginated gig grid with bookmarking and autocomplete search, backed by a word-tokenized Django search endpoint.

About

I'm a frontend developer who's spent the last stretch building one product end to end rather than a portfolio of small demos — which means I've had to own the parts that don't show up in a component library: state that has to survive a page refresh, checkout flows that can't silently fail, chat that has to stay in sync across two WebSocket channels.

I like working close to the backend, not because I want to be a backend developer, but because the best frontend decisions come from understanding what the API can and can't promise you.
